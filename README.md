# Price Doubler JS 💰

## About the Project

Price Doubler JS is a simple web application that doubles one or more prices entered by the user. It was created using HTML, CSS, and JavaScript as a beginner-friendly practice project.

The application allows users to enter multiple prices separated by commas and displays the doubled values.

## Features

- Enter one or more prices separated by commas.
- Double multiple prices at once.
- Validate empty input.
- Check for missing prices.
- Display an error message when invalid numbers are entered.
- Includes separate Home, About, Name, and Practice pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the Price Doubler application.
2. Enter one or more prices separated by commas.
3. Click the **Double Prices** button.
4. View the doubled prices displayed on the screen.

### Example

**Input:**

```text
10, 20, 30
```

**Output:**

```text
20, 40, 60
```

## Validation

The application checks the user's input and displays helpful messages when:

- No prices are entered.
- A price is missing between commas.
- An invalid number is entered.
